주일예배 PDF 만들기 - 사용법
==============================

1. WorshipPDF.exe 를 원하는 폴더(예: 바탕화면\예배PDF)에 넣습니다.
   처음 실행하면 그 폴더에 output, 주보, hymns, data 폴더와 weekly.yaml 이 생깁니다.

2. 주보 한글 파일(.hwp / .hwpx)을
   - WorshipPDF.exe 아이콘 위에 끌어다 놓거나
   - 프로그램 창에 끌어다 놓거나
   - [주보 파일 선택] 버튼으로 고르면
   예배 PDF 가 output 폴더에 만들어지고 바로 열립니다.

3. 창에 [확인 필요] 가 나오면 (예: 찬송가 제목, 악보)
   [입력 내용 고치기] 로 weekly.yaml 을 고치고 저장한 뒤
   [고친 내용으로 다시 만들기] 를 누릅니다.
   한 번 입력한 찬송가 제목·교독문·성경 말씀·찬양 가사는 기억해서 다음부터 자동으로 채웁니다.

4. 찬송가 악보를 자동으로 못 받으면
   https://bibletoppt.com/hymn/hymnppt/no-bg 에서 받은 파일을
   [악보 넣는 폴더] (hymns\inbox) 에 넣습니다. 파일명에 장 번호가 있어야 합니다. (예: 455장.pptx)
   PowerPoint 가 설치돼 있으면 PPT 를 가장 정확하게 변환합니다.

※ 윈도우가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행] 을 누르세요.
   (서명하지 않은 프로그램이라 처음 한 번 나오는 경고입니다)
