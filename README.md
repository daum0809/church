# 주일예배 PDF 자동 만들기 (광염교회)

## 가장 쉬운 방법: 프로그램(WorshipPDF.exe)

**주보 한글 파일을 프로그램에 넣으면 예배 PDF 가 바로 만들어집니다.** 파이썬 설치가 필요 없습니다.

1. **[WorshipPDF-windows.zip 내려받기](https://github.com/daum0809/church-worship-automation/releases/latest/download/WorshipPDF-windows.zip)**
   (항상 최신 버전 링크) → 압축을 풉니다.
2. `WorshipPDF.exe` 를 원하는 폴더에 두고 실행합니다.
3. 주보 `.hwp`/`.hwpx` 를 **창에 끌어다 놓거나**, exe 아이콘 위에 놓거나, [주보 파일 선택] 을 누릅니다.
4. `output` 폴더에 PDF 가 생기고 바로 열립니다. [확인 필요] 가 있으면
   [입력 내용 고치기] → [고친 내용으로 다시 만들기].

자세한 사용법은 `docs/사용법.txt` (exe 와 함께 들어 있음).
파이썬이 설치된 PC 에서는 `프로그램_실행.bat` 으로 같은 창을 띄울 수 있습니다.

`templates/base.pdf` (2026-10-11 주일예배 PDF) 디자인을 그대로 쓰고,
**매주 바뀌는 부분만 `weekly.yaml` 에 입력**하면 예배 때 띄울 PDF가 만들어집니다.

## 핸드폰에서 쓰기

핸드폰 인터넷 창(크롬·사파리·삼성 인터넷)에서 주보 파일을 올리면 PDF 가 만들어집니다.
화면에서 [확인 필요] 항목을 고치고, 빠진 찬송가 악보도 바로 올릴 수 있습니다.

**방법 1 — 교회 PC 를 켜 두고 같은 와이파이에서 (설치·비용 없음)**
1. PC 에서 `WorshipPDF.exe` 실행 → **[핸드폰으로 쓰기]** 누르기
   (윈도우 방화벽 창이 뜨면 '허용')
2. 창에 나온 주소(예: `http://192.168.0.10:8000`)를 핸드폰 인터넷 창에 입력
3. [주보 파일 선택] → 카톡/메일로 받은 주보 hwp 선택 → [PDF 보기 / 저장]

**방법 2 — 폰만으로, PC·서버 없이 (GitHub Pages, 무료)**

주소 하나만 열면 됩니다: **https://daum0809.github.io/church-worship-automation/**
(폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다)

- PDF 를 **폰 안에서** 만듭니다. 주보 파일은 인터넷으로 나가지 않습니다.
- 처음 한 번은 프로그램을 내려받느라 1~2분 걸립니다 (약 38MB, 와이파이 권장). 그다음부터는 빠릅니다.
- 입력해서 기억시킨 찬송가 제목·교독문, 올린 악보는 그 폰의 브라우저에 저장됩니다.
  (브라우저 기록/사이트 데이터를 지우면 사라집니다)
- 찬송가 악보는 빠진 곡마다 [사이트에서 받기] → [파일 올리기]로 넣습니다 (아래 "찬송가 악보 자동 받기" 참고).
- 처음 한 번만 설정이 필요합니다: 저장소 **Settings → Pages → Source: Deploy from a branch →
  Branch: `gh-pages` / `/ (root)` → Save**.

**방법 3 — 인터넷 서버에 올려 쓰기 (Render 무료, 선택)**

비밀번호를 걸어 쓰고 싶거나 악보 자동 다운로드까지 서버에서 하고 싶을 때만 필요합니다.
1. [render.com](https://render.com) 에 GitHub 계정으로 가입
2. **New → Blueprint** → 이 저장소 선택 → `WORSHIP_PASSWORD`(접속 비밀번호) 입력 → 만들기
3. 몇 분 뒤 나오는 주소를 핸드폰에서 열기 (아이디는 아무거나, 비밀번호는 위에서 정한 것)
   - 무료 서버는 안 쓰면 잠들어서 첫 접속이 1분쯤 걸리고, 다시 시작하면 저장 내용이 초기화됩니다.

## 찬송가 악보 자동 받기

악보는 [bibletoppt.com 배경없음 찬송가](https://bibletoppt.com/hymn/hymnppt/no-bg) 에서 가져옵니다.
사이트의 [PPT 다운로드] 버튼과 같은 순서로(10초 기다림 → 허가 → 파일) 필요한 곡만 한 곡씩 받아
PDF 화면으로 바꾸고, 한 번 받은 곡은 저장해 두고 다시 씁니다.

| 쓰는 방법 | 악보 |
|---|---|
| PC 프로그램(`WorshipPDF.exe`), 명령줄, PC 를 서버로 쓰는 폰 화면, Render | **자동으로 받습니다** (곡마다 10초) |
| 미리 받아 두기 | PC 프로그램의 **[찬송가 미리 받기]** (또는 `python make_worship.py --prefetch 전체`). 전체 645곡은 약 2시간, 400~500MB. 곡마다 10초 대기를 지키며 한 곡씩 받고, 중간에 멈춰도 이어받습니다. 저장된 악보는 PC 에서도, PC 를 서버로 쓰는 폰 화면에서도 바로 쓰입니다 (비공개 — 이 PC 에만 저장) |
| 폰 단독(GitHub Pages) | 사이트가 다른 주소의 웹페이지에서 직접 받는 것을 막아 자동은 안 됩니다. 빠진 곡마다 **[사이트에서 받기]**(해당 곡 페이지로 바로 이동) → 사이트에서 PPT 다운로드 → **[파일 올리기]**. 한 번 올리면 폰에 기억합니다 |

## 주보(한글 파일)로 바로 만들기 ← 가장 간단

1. 이번 주 주보 `.hwp` 또는 `.hwpx` 파일을 `주보로_만들기.bat` 위에 **끌어다 놓기**
   (또는 `주보` 폴더에 넣고 `주보로_만들기.bat` 더블클릭 → 가장 최근 파일 사용)
2. 주보의 예배 순서를 읽어 `weekly.yaml` 을 채우고 PDF 까지 만듭니다.
3. 주보에 없는 내용이 있으면 화면에 **[확인 필요]** 로 알려 줍니다.
   그 부분만 `입력하기.bat` 으로 채운 뒤 `만들기.bat` 을 실행하세요.

주보에서 읽는 것: 날짜, 입례찬송·영광송·찬송·봉헌찬송 장(과 제목), 교독문 번호,
대표기도자, 성경봉독 본문·봉독자, 찬양 곡명·성가대·작곡자, 설교 제목·본문·설교자,
**교회소식 전체**(항목이 많으면 여러 화면으로 자동 나눔, 오른쪽 아래 "1 / 3" 표시).
주보에 교독문·성경 본문이 실려 있으면 그것도 그대로 씁니다.
순서 이름(입례찬송, 대표기도, 성경봉독, 설교 …)을 기준으로 찾기 때문에
`……` 점선으로 이어진 주보와 표(순서|내용|담당) 형식 주보 모두 됩니다.

**한 번 입력하면 기억합니다** (`data/` 폴더): 찬송가 제목, 교독문 본문, 성경 말씀,
찬양 작곡자·가사. 그래서 처음 몇 주만 채워 넣으면 그 뒤로는 거의 주보만으로 끝납니다.

- 성경 본문 내용은 저작권 때문에 들어 있지 않습니다. 성경 텍스트 파일을
  `data/bible/` 에 넣어 두면(한 줄에 한 절: `눅10:36 네 생각에는 …`) 자동으로 채웁니다.
- 암호가 걸렸거나 '배포용'으로 저장된 한글 문서는 읽을 수 없습니다.

## 매주 하는 일 (윈도우, 직접 입력)

1. `입력하기.bat` 더블클릭 → 메모장에서 `weekly.yaml` 수정 후 저장
2. `만들기.bat` 더블클릭 → `output/주일예배_YYYY-MM-DD.pdf` 생성, 폴더가 자동으로 열림

(맥/리눅스: `python3 make_worship.py`)

처음 한 번만: [Python 3.10+](https://www.python.org/downloads/) 설치
(설치 화면에서 **Add python.exe to PATH** 체크). 필요한 패키지는 `만들기.bat` 이 알아서 설치합니다.

## 입력하는 항목 (`weekly.yaml`)

| 항목 | 화면 |
|---|---|
| 날짜 | 표지 왼쪽 위 (비우면 다가오는 주일) |
| 입례찬송 장/제목 | 입례 찬송 화면 (`악보: true` 면 악보도) |
| 영광송 장/제목 | 영광송 화면 + 악보 |
| 교독 제목/본문 | 공동기도 화면 + 교독 화면 (인도=흰색, 회중=노란색) |
| 찬송 장/제목 | 찬송 화면 + 악보 |
| 대표기도 이름/직분 | 대표기도 화면 |
| 성경봉독 봉독자/본문/말씀 | 성경봉독 화면 + 절마다 한 화면 (마지막에 "(다같이) 아멘." 자동) |
| 찬양 성가대/곡명/작곡/가사 | 찬양 화면 |
| 말씀 제목/본문/설교자 | 말씀선포 화면 |
| 봉헌찬송 장/제목 | 봉헌 화면 + 악보 |
| 교회소식 | 교회소식 화면 (넘치면 여러 장) |

사도신경, 응답송, 봉헌기도, 주의 기도(635장), 축도, 마침 화면은 원본 그대로입니다.
교회소식은 `교회소식:` 칸에 적은 내용으로 바뀌고, 비워 두면 원본 화면 그대로입니다.

## 찬송가 악보

악보는 [bibletoppt.com 배경없음 찬송가](https://bibletoppt.com/hymn/hymnppt/no-bg) 에서 가져옵니다.

1. `hymns/076.pdf` 처럼 한 번 만든 악보는 저장해 두고 다시 씁니다.
   (원본 PDF에 있던 76·218·478·635장은 이미 들어 있습니다.)
2. 없으면 사이트에서 자동으로 찾아 받습니다.
3. 자동 다운로드가 안 되면 사이트에서 직접 받은 파일(PPT/PPTX/PDF/ZIP/그림 폴더)을
   `hymns/inbox/` 에 **파일명에 장 번호가 들어가게** 넣고 다시 실행하세요. 예: `hymns/inbox/305장.pptx`

PPT → 그림 변환은 PowerPoint(윈도우, `pip install pywin32` 필요) 또는
[LibreOffice](https://ko.libreoffice.org/) 가 있으면 가장 정확합니다. 둘 다 없어도
`.pptx` 는 슬라이드 속 그림을 꺼내서 만듭니다. 악보 화면은 흰 여백을 잘라 화면에 꽉 차게 맞춥니다.

> 개발 환경에서는 bibletoppt.com 접속이 막혀 있어 자동 다운로드는 실제 사이트로 시험하지 못했습니다.
> 실패하면 위 3번 방법으로 넣으면 되고, 오류 메시지에 방법이 나옵니다.

## 글꼴

원본 디자인 글꼴은 **TT옴니고딕(TTOmniGothicM)** 입니다. 이 글꼴이 PC에 설치돼 있으면
자동으로 그 글꼴을 쓰고, 없으면 함께 들어 있는 무료 글꼴 Pretendard(OFL)로
글자 높이·위치를 맞춰 씁니다. 다른 글꼴을 쓰려면 `weekly.yaml` 의 `설정 > 글꼴` 에 파일 경로를 적으세요.

## 디자인을 바꾸고 싶을 때

`templates/base.pdf` 를 새 디자인 PDF로 바꾸고, 페이지 순서가 달라지면
`worship/layout.py` 의 페이지 번호만 맞춰 주면 됩니다.

## 파일 구성

```
weekly.yaml          매주 입력
app.py               프로그램 창 (exe 로 만들어짐)
web_page.html        핸드폰 화면 (서버용/폰 안에서 만드는 용 같이 씀)
pyworker.js, worship/browser.py  폰 브라우저 안에서 파이썬으로 PDF 만들기
tools/build_site.py  GitHub Pages 사이트 조립 (.github/workflows/build-site.yml 이 자동 실행)
web.py               같은 와이파이/서버용 웹 서버
Dockerfile / render.yaml 웹 화면을 인터넷 서버에 올릴 때
make_worship.py      명령줄 실행 파일
worship/run.py       주보/weekly.yaml → PDF (창과 명령줄이 같이 씀)
worship/paths.py     파일 위치 (exe 로 실행하면 exe 옆 폴더에 저장)
.github/workflows/build-windows.yml   윈도우 exe 자동 빌드
만들기.bat / 입력하기.bat
주보로_만들기.bat     주보 한글 파일 → PDF
worship/hwp.py       한글(.hwp/.hwpx) 글자 꺼내기
worship/bulletin.py  주보에서 예배 순서 읽기
worship/memory.py    입력했던 내용 기억 (data/)
worship/bible.py     성경 본문 위치 읽기, data/bible 에서 말씀 찾기
worship/build.py     화면별로 글자 바꾸기
worship/hymns.py     찬송가 악보 받기/변환/저장
worship/text.py      글꼴, 글자 지우기/쓰기
worship/layout.py    원본 PDF 페이지 번호
templates/base.pdf   원본 디자인
hymns/               악보 저장소 (inbox/ 에 직접 받은 파일)
fonts/               Pretendard (SIL OFL 1.1)
```
