# church-worship-automation

## 🎚 stem_splitter — 노래를 **보컬 / 반주 / 이펙트** 3가지로 분리

보컬·반주 2분리는 흔합니다. 이 도구의 핵심은 **이펙트(리버브·에코·딜레이 같은 공간계 효과)까지
따로 떼어내는 3분리**입니다. 필요하면 악기별 6분리도 됩니다.

| 모드 | 결과 |
|---|---|
| `3way` (기본) | ① 보컬(효과 제거된 마른 목소리) ② 반주(효과 제거된 악기) ③ **이펙트**(리버브·에코만) |
| `fx-detail` | 이펙트를 **종류별로** 분리 + 분리 불가능한 이펙트 분석 (아래 참고) |
| `6stem` | 보컬 / 드럼 / 베이스 / 기타 / 피아노 / 기타악기(other) |
| `all` | 위 세 가지 모두 |

### 동작 원리 (3way)

```
원곡 ─[BS-Roformer 보컬 분리]─┬─ 보컬(효과 포함) ─[DeEcho-DeReverb]─┬─ ① 마른 보컬
                               │                                    └─ 보컬 이펙트 ─┐
                               └─ 반주(효과 포함) ─[DeEcho-DeReverb]─┬─ ② 마른 반주   ├─ ③ 이펙트
                                                                    └─ 반주 이펙트 ─┘
```

`extras/` 폴더에는 효과가 남아 있는 보컬·반주와 보컬 이펙트·반주 이펙트를 각각 따로 저장합니다
(예: "리버브 낀 보컬만", "반주의 잔향만").

### 이펙트 상세 모드 (`--mode fx-detail`)

이펙트는 두 종류가 있습니다.

**① 원음 위에 덧붙는 이펙트 → 트랙으로 분리**

| 파일 | 내용 |
|---|---|
| `1_lead_vocals` | 리드 보컬 (리버브·에코·노이즈 제거) |
| `2_backing_vocals` | 백보컬·화음 |
| `3_accompaniment` | 반주 (리버브·에코 제거) |
| `4_reverb` | 리버브(잔향) — 보컬 + 반주 |
| `5_echo_delay` | 에코·딜레이 — 보컬 + 반주 |
| `6_crowd` | 관중·박수·함성 (라이브 음원) |
| `7_noise` | 보컬의 잡음·히스 |

**② 원음 자체를 바꾸는 이펙트 → 분리 불가, 사용 여부·강도만 추정** (`report.json` 의 `effect_analysis`)

| 이펙트 | 판정 방법 |
|---|---|
| 오토튠 | 음정이 반음 격자에 붙어 있는 비율 |
| 보컬 컴프레서 | 0.4초 단위 음량의 흔들림 |
| 마스터링 리미터·클리핑 | 피크 대비 평균 음량(크레스트 팩터), 최대치에 붙은 샘플 |
| 코러스·더블링·스테레오 확장 | 리드 보컬의 좌우 차이 성분 |
| EQ 음색 | 밝음/보통/어두움만 표시 |
| 디스토션, 플랜저·페이저 | 신뢰할 방법이 없어 **판정하지 않음** |

**검증 결과** — 리버브와 에코를 정해진 양만큼 섞은 테스트 곡에서, 각 트랙이 정답과 얼마나 같은지(상관계수, 1이 완벽):

| 트랙 | 정답과의 상관 | 비고 |
|---|---|---|
| 리드 보컬 | 0.93 | |
| 반주 | 0.97 | |
| 리버브 | 0.55 | 다른 소리 섞임 적음, 양은 실제보다 적게 잡힘 |
| 에코·딜레이 | 0.54 | 반주 소리가 일부 섞임, 리버브 일부를 에코로 잡음 |
| 노이즈 (단독 테스트) | 0.87 | |

리버브와 에코는 둘 다 "원음의 지연된 복사본"이라 AI 도 완벽히 구분하지 못합니다.
두 트랙을 합친 "전체 이펙트"는 실제 양에 가깝게 잡힙니다.

### 설치

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
ffmpeg 가 필요합니다 (mp3/m4a 읽기). 처음 실행할 때 AI 모델(3way 약 0.9GB, fx-detail 포함 시 약 2.8GB)을 자동으로 받습니다.

### 사용법

```bash
python -m stem_splitter 노래.mp3                    # 보컬 / 반주 / 이펙트
python -m stem_splitter 노래.mp3 --mode 6stem       # 악기별
python -m stem_splitter 노래.mp3 --mode fx-detail   # 이펙트 종류별 분리 + 분석
python -m stem_splitter 노래.mp3 --mode all         # 전부
python -m stem_splitter 찬양폴더/ -o 결과폴더         # 폴더 일괄 처리
python -m stem_splitter 노래.mp3 --exact            # 세 트랙 합 = 원곡 (정확 복원)
python -m stem_splitter 노래.mp3 --fast             # 빠른 모델
```

결과 (`separated/노래/`):
```
노래_1_vocals.wav          ① 보컬
노래_2_accompaniment.wav   ② 반주
노래_3_effects.wav         ③ 이펙트
extras/                    효과 포함 보컬·반주, 보컬 이펙트만, 반주 이펙트만
노래_report.json           에너지 비율, 복원 정확도(SNR)
```

### 참고
- **속도**: CPU 에서 3분 곡 기준 수십 분 걸릴 수 있습니다. NVIDIA GPU 가 있으면
  `pip install "audio-separator[gpu]"` 로 바꾸면 수십 배 빨라집니다.
- **`--exact`**: 기본값은 이펙트를 AI 모델이 직접 뽑습니다(더 깨끗함). `--exact` 는
  이펙트 = 원곡 − 보컬 − 반주 로 계산해서 세 트랙을 합치면 원곡과 정확히 같아집니다
  (대신 분리 잔여물이 이펙트에 섞임).
- **저작권**: 분리한 음원을 예배·연습용으로 쓰는 것과 별개로, 재배포·공연 시에는 원곡 저작권 및
  교회 저작권 라이선스(CCLI 등) 범위를 확인하세요.
